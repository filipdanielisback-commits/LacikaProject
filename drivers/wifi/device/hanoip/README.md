# Moto G60 (hanoip) Wi-Fi research

**Status: RESEARCH — chipset not yet independently confirmed.**

## Known device-level information

Motorola's regulatory declaration for Moto G60 model XT2135-1 lists WLAN support for IEEE 802.11a/b/g/n/ac. The declaration does not identify the wireless chipset.

A third-party schematic indexed online labels a wireless component WCN3980 on a Hanoi board. This is a lead for further verification only. It must not be treated as proof that all Moto G60 variants use this exact component.

## Questions to resolve
