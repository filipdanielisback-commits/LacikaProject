# Moto G60 software research

**Status: planning and compatibility investigation.**

## Topics to document

- Android platform and kernel version associated with the exact test variant.
- Publicly documented device interfaces.
- Relevant open-source platform components and their licences.
- Known differences between Android/Linux assumptions and Darwin/XNU assumptions.
- Areas where documentation is missing.

## Current limitations

No LacikaProject kernel integration, complete user space, device boot or hardware feature has been verified on the Moto G60.

Do not treat another project's configuration as a drop-in configuration for this device. Use external projects as references, document differences, and keep LacikaProject's code original.
