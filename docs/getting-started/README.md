# Getting started

LacikaProject is an experimental research project, not a ready-to-install operating system.

## Before exploring

1. Read the [project overview](../PROJECT.md).
2. Check the [current device status](../DEVICE_SUPPORT.md).
3. Review the [architecture overview](../ARCHITECTURE.md).
4. Read the [contribution guidelines](../../CONTRIBUTING.md).

## What is available today?

The repository contains research notes, documentation, draft configuration examples, and a Wi-Fi driver scaffold. These materials are useful for study and organization; they do not form a bootable system.

## Development environment

A reproducible build environment and tested end-to-end build procedure have not yet been established. Do not treat generic XNU build instructions as LacikaProject build instructions.

## Reporting an issue

Include the repository commit, file or component involved, what you expected, what happened, and sanitized logs where relevant. Never include passwords, tokens, private keys, personal data, or proprietary firmware.
