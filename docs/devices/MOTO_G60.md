# Motorola Moto G60 — research overview

**Target codename:** `hanoip`  
**Project status:** experimental research; no verified port.

## Scope

This page collects device-specific research questions. It is not a hardware compatibility declaration or a set of installation instructions.

## Research checklist

- [ ] Confirm the exact model and regional variant.
- [ ] Record reliable sources for the SoC and board information.
- [ ] Identify available public hardware documentation.
- [ ] Record display, storage, audio, USB, power, and connectivity components with source links.
- [ ] Separate confirmed identifiers from assumptions.
- [ ] Map each hardware component to available upstream documentation or driver research.
- [ ] Record unresolved questions and conflicting reports.

## Evidence rules

For each hardware fact, record its source, date checked, exact variant, and confidence. Mark uncertain values as **unconfirmed** rather than filling gaps with guesses.

## Current limitations

- No successful LacikaProject boot has been confirmed.
- No complete device port is implemented.
- XNU integration is not implemented or verified.
- The Wi-Fi work is a research scaffold, not a functional driver.
