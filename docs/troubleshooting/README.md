# Troubleshooting

This page is a place to collect reproducible problems as the project develops. It does not imply that a working device boot or build procedure exists.

## When reporting a problem

Include:

- The exact repository commit.
- The file, component, or experiment involved.
- Device model and variant, if relevant.
- Host operating system and tool versions.
- The action attempted, without private credentials.
- The complete error message with sensitive information removed.
- What changed since the last known state.

## Common documentation misunderstandings

**Does the Moto G60 folder mean the phone is supported?**  
No. It identifies the research target only.

**Does a Darwin or XNU note mean XNU has been ported?**  
No. Research notes are not an implementation.

**Does the Wi-Fi folder mean wireless networking works?**  
No. LacikaWiFi is currently a scaffold.

**Is there a public bootable release?**  
No confirmed bootable release is available.

## Security and privacy

Do not publish passwords, access tokens, private keys, account identifiers, personal data, or proprietary firmware dumps in issues or logs.
