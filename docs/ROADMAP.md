# Development roadmap

This roadmap records intended work. It does not promise delivery dates.

## Phase 1 — repository foundation

- [x] Establish project and contribution documentation.
- [x] Create device-specific research notes.
- [x] Add draft Darwin input configuration examples.
- [ ] Select and document a project licence.
- [ ] Review all existing repository claims for evidence and accuracy.

## Phase 2 — research and architecture

- [ ] Build a sourced Moto G60 hardware inventory for the exact model variant.
- [ ] Document relevant XNU concepts and upstream source references.
- [ ] Map major compatibility questions without assuming they are solved.
- [ ] Define the boundary between open-source code and user-supplied proprietary inputs.

## Phase 3 — host-side development

- [ ] Define a reproducible host-side development environment.
- [ ] Expand unit tests that do not require a phone or firmware modification.
- [ ] Add static checks for documentation and source formatting.
- [ ] Review LacikaWiFi interfaces and test coverage.

## Phase 4 — feasibility review

- [ ] Evaluate whether the required platform interfaces are documented.
- [ ] Record blockers and unresolved compatibility requirements.
- [ ] Review any proposed physical-device work with an experienced hardware developer.
- [ ] Publish a feasibility report before making boot or support claims.

## Current milestone

**Milestone: research foundation.** No bootable image, confirmed phone boot, or public device port is available.
