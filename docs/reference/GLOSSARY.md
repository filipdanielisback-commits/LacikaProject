# Glossary

- **Android** — an operating-system platform commonly used on phones; device builds include Linux-based kernels and Android user space.
- **Boot chain** — the sequence of firmware and software stages that starts a device.
- **Device tree** — a structured description of hardware used by some systems to communicate platform details to a kernel.
- **Darwin** — Apple's operating-system foundation, including the XNU kernel and other open-source components.
- **Driver** — software that provides an interface between an operating system and a hardware component.
- **hanoip** — the device codename used by this project for its Motorola Moto G60 research target.
- **Host-side test** — a test executed on a development computer rather than on the target phone.
- **Kernel** — the core part of an operating system responsible for low-level resource and hardware management.
- **Port** — adapting software to a different hardware platform or operating-system environment.
- **Scaffold** — an initial code or directory structure that does not yet provide the complete intended functionality.
- **SoC** — system-on-chip; an integrated chip containing a processor and other platform components.
- **UEFI** — a firmware interface specification used by some platforms to start operating systems.
- **Verified result** — a narrowly stated claim supported by reproducible evidence for a defined environment.
- **XNU** — the hybrid kernel used by Darwin-based Apple operating systems.

This glossary is educational. A term appearing here does not mean LacikaProject has implemented the related technology.
