# Development Notes

This document describes the current organization of the project, not a completed build procedure.

## Current focus

1. Organize repository documentation.
2. Record device and platform research.
3. Develop the project website separately from experimental system work.
4. Add code only when its purpose, requirements, and limitations are documented.

## Recording an experiment

Where relevant, record:

- Date and a short experiment title.
- Device model and hardware variant.
- Software, firmware, and tool versions.
- What was attempted and why.
- What happened, including errors.
- Whether the result is verified, inconclusive, or not reproduced.

Do not publish secrets or personal data in logs.

## Build status

No bootable image or working device port is claimed by this document. Build instructions will be added only after they have been tested and can be described accurately.
