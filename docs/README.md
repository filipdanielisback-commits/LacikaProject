## Research status language

Use **planned**, **hypothesis**, **research**, **experimental**, or **verified** precisely. A folder, draft configuration, source-code reference, or host-side test is not evidence that a phone port works.

The current target is the Motorola Moto G60 (`hanoip`). No successful LacikaProject boot, complete XNU integration, functional Wi-Fi driver, GPU acceleration, or public bootable release is currently claimed.
