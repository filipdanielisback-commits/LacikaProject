# XNU research

This directory is reserved for LacikaProject's notes about the XNU kernel.

## Current status

No LacikaProject XNU fork, device-specific kernel integration or Moto G60 boot is claimed here. This directory intentionally begins with documentation rather than copied upstream source.

## Research guidelines

- Prefer official public upstream documentation and source references.
- Record the exact upstream revision when discussing implementation details.
- Keep third-party code provenance and licence information with any future contribution.
- Do not copy code without checking its licence and compatibility.
- Distinguish general XNU behaviour from assumptions about the Moto G60.

## Key distinction

XNU is a kernel foundation, not a complete iOS distribution and not a complete device port by itself.
