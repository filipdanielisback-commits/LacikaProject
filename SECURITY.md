# Security Policy

## Scope

This repository is an experimental research project. Security reports are welcome for vulnerabilities in code or project infrastructure maintained here.

## Reporting a concern

Please do not publish details of an unpatched vulnerability in a public issue.

If GitHub's private vulnerability reporting is enabled for this repository, use the repository's **Security** tab to submit a private report. Otherwise, contact the repository owner privately through GitHub and share only the information needed to understand the issue.

Do not include passwords, private keys, personal information, or unrelated third-party data in a report.

## Expectations

The project may have limited maintenance capacity. A report is appreciated, but a response or fix timeline cannot be guaranteed.
